# Demo: browser phone call simulator

Live: open `/phone` on the web app. Fake build: same page, demo student 9876543210.

1. Tap **Call** (or press a key). Status goes Connecting, then Call active, and the timer runs.
2. Type the student ID (phone number) on the keypad or keyboard, press **#** (or Enter). Live demo student: 6000000101.
3. Type the PIN **123456**, press **#**. Or tap **Use demo student** (labelled demo shortcut).
4. Hear the welcome. Press **2**, then **1** for the course, **1** for a lesson (or **1** to continue a lesson).
5. Hear the question. Press **1-4** to choose, **7** to hear your choice, **8** to clear, **9** to confirm.
6. Hear Correct / Not quite. Missed questions come back at the end. Finish the lesson.
7. Open the app as the same student: the lesson is done and XP went up.
8. Teacher home (teacher 6000000099): "Phone simulator activity" shows users, sessions, lessons, right/not quite, minutes, interrupted calls and App vs Phone simulator.
9. Parent child page (parent 6000000201): the same card for that child.
