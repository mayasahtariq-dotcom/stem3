# Web Phase 4 demo: the game layer

Run with the fakes (`pnpm --filter @mooshala/web dev`, http://localhost:3000). Student phone `9876543210`, code `123456`. Menu → **Reset demo data** first.

1. **Golu Pot.** On the farm a clay pot wobbles next to Golu (earned by yesterday's lesson). Tap it → **Open the pot**: gems or a sticker, decided by the server. No odds are shown. The pot is gone afterwards.
2. **Quest board.** Dock → **Quests** (or signboard → Quest board). "Earn 10 XP today" is done → **Claim 20 gems**. It shows Claimed; reload, still claimed; the HUD gems went up once.
3. **Finish a lesson** and come back: "Finish a lesson" is now claimable and a new pot is waiting.
4. **Village fair.** Dock → **League**: this week's XP noticeboard, Asha highlighted, the top 3 in the move-up zone, Ramu marked as learning by phone. "Gems never change your place."
5. **Badges and Golu's growth.** Dock → **Profile**: Golu the calf with XP to grow, and the badge shelf (First harvest, Three sunny days, Hundred club earned; others show progress, e.g. Word collector 1 of 5). Save four more words in the word book and the badge appears (+50 gems).
6. **Growth in 3D.** Golu on the farm is a calf now; at 500 XP she's a full cow and at 2,000 a champion with a gold bell.
